regulators' manuals, company reports, academic papers and the press.

## How to read them

Each note starts with a section that defines its marks. The marks differ
a little between notes, and they separate 3 kinds of statement:

- A statement that was read in a named source during the research.
- A statement that was recalled and not checked again. Check it before
  you quote it.
- An estimate. No source gives the value.

Each note ends with model recommendations. The code does not follow
every recommendation. [../business.md](../business.md) and the comments
in each package say what the model uses.

## What these notes are not

The notes are working notes. They are not held to the writing standard
in [../style.md](../style.md), and `scripts/prose.py` is not run on
them.

Quotations longer than a few words from the press, from papers and from
company filings are paraphrased. Quotations from US court records and US
government documents are kept as printed. One of them, the 1982 telephone
call in section 2.2 of [competition.md](competition.md), contains
profanity as the court record has it.
